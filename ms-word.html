1. 🖥️ Microsoft Word Basics

What is Microsoft Word?

Microsoft Word is a word processing software used to create, edit, and format documents.

Microsoft Word एक word processing software है जिसका उपयोग document बनाने, edit करने और format करने के लिए किया जाता है।

Who developed Microsoft Word?

Microsoft Word was developed by Microsoft.

Microsoft Word को Microsoft कंपनी ने विकसित किया है।

When was Microsoft Word first released?

Microsoft Word was first released in 1983.

Microsoft Word पहली बार 1983 में जारी किया गया था।

What is the use of Microsoft Word?

Microsoft Word is used to write letters, reports, assignments, and other documents.

Microsoft Word का उपयोग letter, report, assignment और अन्य documents लिखने के लिए किया जाता है।

Default File Extension

The default file extension of Microsoft Word is .docx.

Microsoft Word की default file extension .docx होती है।

What is a Document?

A document is a file created in Microsoft Word that contains text, images, or other information.

Microsoft Word में document एक file होती है जिसमें text, image या अन्य जानकारी होती है।

What is the Ribbon?

The Ribbon is the top toolbar that contains tabs and tools used to edit and format documents.

Ribbon ऊपर का toolbar होता है जिसमें tabs और tools होते हैं जो document को edit और format करने में मदद करते हैं।

2. 📁 File Tab

The File Tab contains options for managing documents, saving, opening, printing and changing Word settings.

1. Home

The Home option shows the main page of the File tab where recent documents and templates can be seen.

Home option File Tab का मुख्य page होता है जहाँ recent documents और templates दिखाई देते हैं।

2. New

The New option is used to create a new blank document or start with a template.

New option का उपयोग नया blank document बनाने या template से document शुरू करने के लिए किया जाता है।

3. Open

The Open option is used to open documents that are already saved on the computer.

Open option का उपयोग computer में पहले से save की हुई files को खोलने के लिए किया जाता है।

4. Info

The Info option shows information about the current document such as file size, permissions, and properties.

Info option में document की जानकारी दिखाई जाती है जैसे file size, permission और properties।

5. Save

The Save option saves the current document so it can be used later.

Save option document को computer में सुरक्षित करता है ताकि बाद में फिर से इस्तेमाल किया जा सके।

6. Save As

Save As is used to save the document with a different name, location, or file format.

Save As का उपयोग document को नए नाम, नई जगह या अलग format में save करने के लिए किया जाता है।

7. Print

The Print option is used to print the document on paper using a printer.

Print option का उपयोग document को printer की सहायता से कागज पर छापने के लिए किया जाता है।

8. Share

The Share option allows users to share the document through email or cloud services.

Share option से document को email या cloud service के माध्यम से दूसरे लोगों के साथ share किया जा सकता है।

9. Export

The Export option is used to change the document into another file format such as PDF.

Export option का उपयोग document को दूसरे format जैसे PDF में बदलने के लिए किया जाता है।

10. Close

The Close option is used to close the current document.

Close option का उपयोग वर्तमान document को बंद करने के लिए किया जाता है।

11. Account

The Account option shows information about the Microsoft account and product details.

Account option में Microsoft account और product की जानकारी दिखाई जाती है।

12. Feedback

The Feedback option allows users to send suggestions or report problems to Microsoft.

Feedback option से user Microsoft को सुझाव या समस्या की जानकारी भेज सकते हैं।

13. Options

The Options menu is used to change the settings of Microsoft Word.

Options menu का उपयोग Microsoft Word की settings बदलने के लिए किया जाता है।

3. 🏠 Home Tab

Clipboard Group

The Clipboard group is used to cut, copy, and paste text or objects in a document.

  • Paste: Insert copied or cut text.
  • Cut: Remove selected text and move it.
  • Copy: Copy selected text.
  • Format Painter: Copy formatting from one text to another.
Clipboard group का उपयोग document में text या object को cut, copy और paste करने के लिए किया जाता है।

Font Group

The Font group is used to change the style and appearance of text such as font type, size, color, and formatting.

  • Font Style: Change the font type.
  • Font Size: Change text size.
  • Bold: Make text darker and thicker.
  • Italic: Make text slanted.
  • Underline: Put a line under text.
  • Text Color: Change the color of text.

Paragraph Group

Paragraph group is used to arrange text alignment and spacing in a document.

  • Align Left: Align text to the left side.
  • Center: Place text in the center.
  • Align Right: Align text to the right side.
  • Justify: Align text equally on both sides.
  • Bullets / Numbering: Create lists.

Styles Group

Styles group is used to apply predefined styles like headings and titles to text.

Editing Group

  • Find: Search for a word or sentence.
  • Replace: Replace one word with another.
  • Select: Select text or objects.

4. ➕ Insert Tab

Pages

  • Cover Page: Inserts a ready-made cover page.
  • Blank Page: Adds a new empty page.
  • Page Break: Starts a new page at the current spot.

Table

Used to insert tables to organize data in rows and columns.

Illustrations

  • Pictures
  • Shapes
  • Icons
  • 3D Models
  • SmartArt
  • Chart
  • Screenshot

Add-ins

Used to add extra tools or features to Word.

Media

Used to insert online videos.

Links

  • Link: Adds a website or file link.
  • Bookmark: Marks a specific place in the document.
  • Cross-reference: Links to another part of the same document.

Comments

Used to add comments or notes in the document.

Header & Footer

  • Header: Adds text or information to the top of every page.
  • Footer: Adds text or information to the bottom of every page.
  • Page Number: Inserts automatic numbering on pages.

Text

  • Text Box: Creates a box to type text anywhere.
  • WordArt: Creates stylish and decorative text.
  • Drop Cap: Makes the first letter of a paragraph large.

Symbols

  • Equation: Writes mathematical formulas.
  • Symbol: Adds special characters or symbols.

5. 🎨 Design Tab

The Design tab is used to change the overall appearance and style of the document.

Document Formatting Group

  • Themes: Change the complete design of the document.
  • Colors: Change the color scheme.
  • Fonts: Change font style for headings and body text.
  • Paragraph Spacing: Control space between paragraphs.
  • Effects: Change visual effects of shapes and graphics.
  • Set as Default: Save selected theme and formatting as default.

Page Background Group

  • Watermark: Add faded text or images in the background.
  • Page Color: Change the background color of the page.
  • Page Borders: Add borders around the page.

6. 📐 Layout Tab

The Layout tab is used to control the page layout and arrangement of text in a document.

Page Setup Group

  • Margins: Set space between text and page edges.
  • Orientation: Change page direction to Portrait or Landscape.
  • Size: Select page size such as A4 or Letter.
  • Columns: Divide text into two or more columns.
  • Breaks: Insert page breaks or section breaks.
  • Line Numbers: Add numbers to each line.
  • Hyphenation: Split long words at the end of a line with a hyphen.

Paragraph Group

  • Indent: Move text away from the margin.
  • Spacing: Control space before and after paragraphs.

Arrange Group

  • Position: Place objects at a specific position.
  • Wrap Text: Control how text flows around images or objects.
  • Align: Align objects properly on the page.

7. 📚 References Tab

The References tab is used to add references, citations, footnotes, and tables of contents in a document.

Table of Contents Group

  • Table of Contents: Create an automatic table of contents.
  • Add Text: Add selected text to the table of contents.
  • Update Table: Refresh the table after changes.

Footnotes Group

  • Insert Footnote: Add a reference at the bottom of the page.
  • Insert Endnote: Add a reference at the end of the document.
  • Next Footnote: Move to the next footnote.

Research Group

Search is used to find information related to selected text.

Citations & Bibliography Group

  • Insert Citation
  • Manage Sources
  • Style
  • Bibliography

Captions Group

  • Insert Caption
  • Insert Table of Figures
  • Cross-reference

Index Group

  • Mark Entry
  • Insert Index

Table of Authorities Group

  • Mark Citation
  • Insert Table of Authorities

8. ✉️ Mailings Tab

The Mailings tab is used to create letters, envelopes, labels, and perform mail merge.

Create Group

  • Envelopes: Create and print envelopes with addresses.
  • Labels: Create and print address labels.

Start Mail Merge Group

  • Start Mail Merge
  • Select Recipients
  • Edit Recipient List

Write & Insert Fields Group

  • Highlight Merge Fields
  • Address Block
  • Greeting Line
  • Insert Merge Field
  • Rules
  • Match Fields
  • Update Labels

Preview Results Group

  • Preview Results
  • Find Recipient
  • Check for Errors

Finish Group

Finish & Merge completes the mail merge and creates final documents.

9. 🔍 Review Tab

The Review tab is used to check spelling and grammar, add comments, track changes, and review the document.

Proofing Group

  • Spelling & Grammar: Checks spelling and grammar mistakes.
  • Thesaurus: Finds synonyms for a selected word.
  • Word Count: Shows words, pages, paragraphs and characters.

Speech Group

Read Aloud: Reads the document text out loud.

Accessibility Group

Check Accessibility: Checks if the document is accessible for all users.

Language Group

  • Translate: Converts text into another language.
  • Language: Sets the proofing language.

Comments Group

  • New Comment
  • Delete Comment
  • Show Comments

Tracking Group

  • Track Changes: Records edits made in the document.
  • Reviewing Pane: Shows tracked changes and comments.

Changes Group

  • Accept
  • Reject
  • Previous / Next

Compare Group

Compare is used to compare two versions of a document.

Protect Group

Restrict Editing limits the editing permissions in a document.

10. 👁️ View Tab

The View tab is used to change how the document is displayed on the screen. It helps in zooming, changing views, and managing windows.

Views Group

  • Read Mode: Displays the document in a reading layout.
  • Print Layout: Shows how the document will look when printed.
  • Web Layout: Shows the document as it would appear on a web page.

Show Group

  • Ruler: Displays rulers to adjust margins and tabs.
  • Gridlines: Shows grid lines to help align objects.
  • Navigation Pane: Helps move through headings, pages and search results.

Zoom Group

  • Zoom
  • 100%
  • One Page
  • Multiple Pages

Window Group

  • New Window
  • Arrange All
  • Split
  • View Side by Side
  • Switch Windows

11. 🆘 Help Tab

The Help tab is used to get help and support for using Microsoft Word. It allows users to search for solutions, tutorials, and information about features.

Help Tab Options

  • Help: Search for help topics and instructions.
  • Contact Support: Get help from Microsoft support services.
  • Feedback: Send suggestions or report problems to Microsoft.
  • Show Training: Provides tutorials and learning materials.
