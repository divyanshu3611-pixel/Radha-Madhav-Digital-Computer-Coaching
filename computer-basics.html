🖥️ Computer Basics

Welcome to the Computer Basics course. Learn the fundamentals of computers in simple language.

Lesson 1 — What is a Computer?

A computer is an electronic device that accepts data, processes it, stores it and produces useful information.

Basic Functions of a Computer

  • Input — Entering data into a computer.
  • Processing — Working on the entered data.
  • Output — Showing the result.
  • Storage — Saving data for future use.

Lesson 2 — Main Parts of a Computer

A computer system have 4 main parts.

  • ⌨️ Input Unit
  • 🖥️Output Unit
  • 🔄 Processing Unit
  • 🧠 Memory Unit

Lesson 3 — Hardware and Software

Hardware

Hardware means the physical parts of a computer that we can see and touch.

Examples: Keyboard, Mouse, Monitor, CPU and Printer.
